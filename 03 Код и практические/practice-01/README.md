Запуск JavaScript в двух средах, типы, условия, цикл while и исправление логических ошибок. Обязательные файлы: js/hello.js, js/types.js, js/progress.js, js/plan.js, js/debug.js. ## Запуск

Для браузера запустить node serve.mjs из корня и открыть http://127.0.0.1:5500/practice-01/. В index.html оставлен script src="./js/hello.js". Для остальных программ доступны types.html, progress.html, plan.html и debug.html; вывод находится в Console.

| Выражение | Расчёт до запуска | Фактическое значение | Тип результата | Причина |

| "8" - 2 | 6 | 6 | number | - приводит операнды к числам |
| Number("8") + 2 | 10 | 10 | number | Явное преобразование |

| Boolean("false") | true | true | boolean | Непустая строка истинна |
| typeof null | "object" | "object" | string | Историческая особенность typeof |
| typeof NaN | "number" | "number" | string | NaN относится к числовому типу; typeof возвращает строку |
