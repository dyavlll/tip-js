# Как запустить и воспроизвести контрольные

Все команды выполняются в терминале. Для обычной установки Node.js используй официальный сайт https://nodejs.org. В комплекте нет сторонних npm-зависимостей: npm install не нужен. На этом компьютере проверено с Node.js v24.22.1.

## Быстрый запуск

Открой папку «Готовая работа» в терминале. Запусти:

```powershell
node serve.mjs
```

Оставь этот терминал открытым. Общий адрес сайта: http://127.0.0.1:5500. Для проверки серверных заданий открой второй терминал в папке practice-05 либо practice-06 и выполни npm start. Если npm недоступен, эквивалентный запуск API без npm:

```powershell
node api/server.mjs
```

API слушает http://127.0.0.1:5505/api. Одновременно должен работать только один API на порту 5505. Остановка — Ctrl+C в его терминале. Для ПР6 npm start также запускает отдельный сайт на порту 5506; при использовании общего serve.mjs можно открывать ПР6 по общему адресу ниже.

## КР2: название и сохранение

Проверка названия: http://127.0.0.1:5500/Проверки%20КР/kr2-1.html.

Для хранения открой http://127.0.0.1:5500/practice-04/. Нажми штатную кнопку сброса исходных данных, выбери «Все». Введи id 20, название «Изучить localStorage», приоритет «Высокий» (value high). Добавь задачу. Перезагрузи страницу по тому же адресу, в том же браузере.

Открой F12 → Application → Storage → Local storage → http://127.0.0.1:5500. Выбери tip-js-practice-04:demo. В JSON должны быть version: 1 и tasks с объектом id 20, title «Изучить localStorage», priority high, completed false. Для отчётного снимка одновременно покажи задачу в списке и открытую запись хранилища. При необходимости уменьши масштаб страницы Ctrl+−, не уменьшая текст до нечитаемого размера.

## КР2: запрос и ошибка

Запусти API именно из practice-05. Открой:

- http://127.0.0.1:5500/Проверки%20КР/kr2-3.html — ожидаются id [4, 13, 34], meta.total 3.
- http://127.0.0.1:5500/Проверки%20КР/kr2-4.html — ожидаются kind http и status 404 с обработкой в catch.

Можно выполнить node src/main.js из practice-05: он показывает контрольный запрос и обработанную ошибку.

## КР2: изменение через API

Останови API ПР5, затем запусти API из practice-06. Открой http://127.0.0.1:5500/practice-06/. Нажми «Сбросить данные» и подтверди сброс учебного набора. Оставь только фильтр статуса «В работе» (completed=false), остальные фильтры очисти; примени фильтры.

Открой F12 → Network; включи фильтр Fetch/XHR и очисти журнал запросов. Отметь выполненной задачу ID 4. В Network должны последовательно появиться PATCH /api/tasks/4 (200), затем GET /api/tasks?completed=false (200). Задача 4 исчезнет из списка; останутся незавершённые id [7, 13, 19, 22, 28, 34]. Это изменение статуса, а не удаление.

Для одного снимка открой столбцы Method, Status и URL/Name; размести Network рядом со списком. В запросе PATCH на вкладке Payload можно дополнительно проверить completed: true. Снимай реальное состояние после действия.

## Если что-то не запускается

«node не является командой»: Node.js отсутствует в PATH. На этом компьютере доступен встроенный исполняемый файл C:\Users\Jaiso\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe. В PowerShell перед полным путём в кавычках нужен оператор &.

EADDRINUSE: порт уже занят другим запуском. Останови предыдущий сервер в его терминале. Не закрывай неизвестные процессы наугад.

404 при открытии страницы: проверь, что serve.mjs запущен из комплекта, и адрес содержит нужную папку. Открытие HTML двойным щелчком через file:// не заменяет HTTP-сервер.

Нет соединения с API: проверь второй терминал и адрес 127.0.0.1:5505. ПР5 доступна только для чтения; для PATCH нужен сервер ПР6.

Задача 20 не восстановилась: проверь одинаковые протокол, хост, порт и профиль браузера. localhost и 127.0.0.1 не следует чередовать при проверке localStorage.
