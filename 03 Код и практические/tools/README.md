# Дополнительные проверки DOM

Эти проверки используют jsdom, а не настоящий браузер. Они не создают скриншоты и не заменяют DevTools. Установка этой дополнительной зависимости не нужна для запуска приложений и стандартных проверок курса.

Из этой папки: npm install, затем node dom-tests.mjs и node dom-experiments.mjs. Вместо npm можно использовать pnpm. Для dom-tests.mjs должен работать API ПР6 на 127.0.0.1:5505. Сценарии сбрасывают только учебный набор этого локального API и создают временные DOM в памяти.
