## URL, ошибки и параллельность

buildUrl соединяет baseUrl и путь без лишнего слеша; URLSearchParams кодирует значения. false сохраняется, undefined/null/пустая строка пропускаются; query не изменяется. Клиент проверяет конфигурацию, Response, response.ok, Content-Type и JSON, различает http/network/timeout/aborted/invalid-response. HTTP-статус проверяется до схемы успешного ответа; 204 превращается в null.

loadInitialData использует Promise.all для независимых задач и категорий. В experiments.mjs проведено по три замера двух задержек80мс последовательно и параллельно; численные результаты сохранены в протоколе, они не захардкожены. Тайм-аут150/20 даёт timeout, внешняя отмена — aborted. При остановленном API реальный запуск main.js дал network, после повторного запуска API снова получен успешный ответ; pr05-network-off.txt и pr05-client-run.txt.
