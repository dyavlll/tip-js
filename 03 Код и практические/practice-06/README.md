## Запуск и архитектура

Из practice-06: npm start запускает API5505 и сайт5506. Без npm: node api/server.mjs в одном терминале, node tools/static-server.mjs в другом. Также доступен общий сайт http://127.0.0.1:5500/practice-06/ при node serve.mjs из корня. Вариант — index.html?dataset=variant. Сервер ПР5 должен быть остановлен.

api-client.js занимается HTTP и ApiError; task-api.js — контрактом предметных методов и схемой ответов; form-validation.js — полями формы; app-controller.js — состоянием, загрузкой и мутациями; task-view.js — безопасным DOM; dom-app.js — событиями и представлением. Готовый api/server.mjs не изменён, данные хранятся в памяти сервера.

Контроллер различает loading/ready/empty/error, отменяет прежнюю загрузку и игнорирует устаревший результат по generation. При неудачном первом запуске retry повторяет загрузку и задач, и категорий. После мутации выполняется GET с текущими фильтрами; кнопки блокируются только на время операции и разблокируются в finally. Форма меняется через API, а не localStorage.
